Seguranca em SO e Sistemas Distribuídos

Seguranca em SO

1

O que é Segurança em Sistemas Operacional

Um Sistema Operacional (SO) é o software fundamental que gerencia os recursos de hardware e software de um dispositivo, servindo como intermediário entre o usuário e a máquina.

2

Ameacas comuns ao SO

Vírus e Malware: Programas maliciosos que podem corromper arquivos, roubar informações ou causar danos ao sistema.

Ransomware: Tipo de malware que bloqueia o acesso ao sistema ou arquivos até que um resgate seja pago.

Phishing: Tentativas de enganar os usuários para que revelem informações confidenciais, como senhas ou dados bancários, por meio de mensagens fraudulentas.

3

Como defendê-la

Atualizações Regulares: Manter o sistema operacional atualizado com os patches de segurança mais recentes para corrigir vulnerabilidades conhecidas.

Antivírus e Antimalware: Utilizar software de segurança para detectar e remover ameaças como vírus, malware e ransomware.

Configurações de Segurança: Configurar corretamente as permissões de arquivos, firewalls e políticas de acesso para limitar o que os usuários e programas podem fazer.

4

Políticas de Acesso e Privilégios

Princípio do Menor Privilégio: Conceito onde usuários e programas possuem apenas as permissões estritamente necessárias para suas funções, evitando o uso desnecessário da conta de Administrador (Root).

Controle de Acesso Baseado em Regras (RBAC): O SO define permissões (Ler, Escrever, Executar) para arquivos e pastas com base no grupo ou papel que o usuário ocupa no sistema.

Biometria e Autenticação Forte: Mecanismos locais integrados ao SO (como o Windows Hello ou Face ID) que substituem ou reforçam senhas tradicionais usando dados biológicos do usuário.

5

Monitoramento e Resiliência

Auditoria e Logs de Eventos: O SO mantém registros detalhados de atividades críticas (como tentativas de login e alterações de arquivos) para que administradores possam investigar invasões.

Criptografia de Disco (BitLocker/FileVault): Tecnologia que embaralha todos os arquivos armazenados no HD ou SSD. Se o dispositivo físico for roubado, os dados continuam inacessíveis sem a chave.

Pontos de Restauração e Backup: Mecanismos que permitem ao SO reverter arquivos de sistema e configurações para um estado seguro anterior caso ocorra uma infecção ou falha grave.

Sistemas Distribuídos

1

O que são Sistemas Distribuídos?

É um conjunto de computadores independentes que se comunicam através de uma rede e trabalham juntos para realizar uma tarefa. Para o usuário final, toda essa estrutura parece funcionar como uma única máquina.

2

Características dos Sistemas Distribuídos

Concorrência: Capacidade de executar múltiplas tarefas simultaneamente.

Escalabilidade: Capacidade de lidar com o aumento da carga de trabalho ou do número de usuários.

Disponibilidade: Garantia de que o sistema esteja disponível quando necessário.

3

Identidade e Federação

Single Sign-On (SSO): Sistema de autenticação que permite ao usuário logar apenas uma vez e ganhar acesso a múltiplos sistemas e servidores independentes na rede distribuída.

Arquitetura Zero Trust (Confiança Zero): Modelo de segurança baseado no princípio de "nunca confiar, sempre verificar". Mesmo que um dispositivo esteja dentro da rede, ele precisa ser reautenticado a cada passo.

Assinaturas Digitais e Chaves Públicas (PKI): Uso de infraestrutura de chaves (criptografia assimétrica) para garantir que as mensagens enviadas entre os servidores não foram alteradas no caminho.

4

Segurança de Perimetro a trafego

Firewalls Distribuídos e IDSs: Sistemas de Detecção de Intrusão que monitoram o tráfego de rede entre todas as máquinas simultaneamente para bloquear comportamentos anômalos.

Ataques Man-in-the-Middle (MitM): Tipo de interceptação onde o hacker se posiciona secretamente entre duas máquinas que estão conversando, conseguindo ler ou até alterar as mensagens transmitidas.

API Gateways Seguros: Um ponto de entrada único e protegido que filtra, autentica e limita a quantidade de requisições enviadas de fora para dentro dos servidores do sistema.

5
